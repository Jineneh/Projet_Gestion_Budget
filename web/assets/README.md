# Médias de l'interface web

Déposez ici vos fichiers, ils s'affichent automatiquement dans la page « Démo et captures » :

- `demo.mp4` : la vidéo de démonstration (idéalement moins de 50 Mo)
  ou `video_url.txt` : un lien YouTube non répertorié, sur une seule ligne
- des captures d'écran `.png` ou `.jpg` (le nom du fichier sert de légende : `tableau_de_bord.png`)
